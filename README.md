# HumanEdit

Skill для рерайта и де-нейросетизации текстов с приоритетом русского языка.

HumanEdit убирает AI-артефакты, вычищает клише, пассив и искусственную симметрию, сохраняет смысл и авторский голос. Skill подходит для бережного рерайта, жёсткой зачистки текста и редакторского разбора.

## Что делает

- Убирает нейросетевые шаблоны и канцелярит.
- Сохраняет голос автора, ритм и интонацию.
- Поддерживает режимы `soft` и `hard`.
- Работает с русским текстом в приоритете, английский поддерживается вторым слоем.
- Помогает получать живой текст без искусственной стерильности.

## Режимы

### soft
Бережный рерайт без заметной перестройки текста.

Подходит, если нужно:
- убрать AI-шум;
- сохранить структуру;
- оставить тон и ритм автора;
- вычистить клише и лишние связки.

### hard
Жёсткая де-нейросетизация с активной перепаковкой текста.

Подходит, если нужно:
- заметно ослабить AI-подпись;
- убрать пассив и безличные обороты;
- сломать искусственную симметрию;
- сделать текст более живым и естественным.

## Использование

В начале запроса укажите режим:

```text
soft: перепиши текст, сохранив стиль автора
```

или

```text
hard: зачисти текст от AI-следов
```
